# 🚀 SpaceNav v.2026 🚀

SpaceNav is a C# .NET Console Application designed to compute optimized paths for astronauts in a grid based cosmic space
---

## System Architecture and key features

* **Adaptive Pathfinding Engine** - calculates path either using Dijkstra if debris are available or simple Breadth First search
* **Interactive Interface** - Choose between random generated map or manually input one through an arrow key driven selection menu
* **Send mission report through email** - Send the mission report using an SMTP connection via email to provided recipient.

## Build and run

### Build

Navigate to project root and run: 
```bash
    dotnet build
```
### Run
```bash
    dotnet run
```
